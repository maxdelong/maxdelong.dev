# Feature Specification: Agentic Dev

**Feature Branch**: `008-agentic-dev`

**Created**: 2026-11-06

**Status**: Implemented

**Input**: User description: "Make a tab for the latest strategies on agentic development. Last I heard: loop engineering, harnesses, etc. What is new today? What tools are recommended? Provide sources and make the page engaging."

## Requirements

- **FR-001**: The site MUST have an Agentic Dev tab that shows the date its research was last checked.
- **FR-002**: The page MUST cover what's new, how the practice got here, what strategies to use and what tools are recommended.
- **FR-003**: Each factual section MUST cite numbered sources, and each source MUST link to the original and show its type, so vendor and news sources can be weighed.
- **FR-004**: Sources MUST have been opened for the page, or say how far they were checked. Sources that couldn't be opened MUST NOT be cited.
- **FR-005**: The page MUST compare common advice against the evidence, including where evidence is missing.
- **FR-006**: The page MUST be interactive, with a level explorer, a reality check, a loop checklist and a tool picker.
- **FR-007**: Tool picks MUST state their basis, and the page MUST disclose that it was written by Claude, made by Anthropic, which also makes Claude Code.

## Assumptions

- The content is a dated snapshot in `lib/agentic-dev/`, updated by hand. Keeping it current is on the page's to-do list.
- The loop checklist is an editorial summary, not a published standard.

Implemented.
